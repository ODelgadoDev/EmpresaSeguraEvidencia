# Empresa Segura

## App Web académica sobre protección de datos en el sector empresarial

**Empresa Segura** es una App Web desarrollada como evidencia para la materia de **Seguridad Informática**, impartida por el profesor **César Medina**.

El proyecto corresponde al **Equipo 3**, cuyo sector asignado es el **sector empresarial**. La aplicación tiene como objetivo explicar de forma clara la importancia del manejo seguro de la información dentro de una empresa, incluyendo el aviso de privacidad, la confidencialidad de los datos, el deslinde de responsabilidad, los riesgos de seguridad y las normas, estándares y leyes aplicables.

## Objetivo del proyecto

Desarrollar una App Web donde se identifiquen normas, estándares y leyes aplicables al manejo de información en el sector empresarial.

La aplicación incluye:

- Aviso de privacidad.
- Confidencialidad de la información.
- Deslinde de responsabilidad.
- Normas, estándares y leyes aplicables.
- Riesgos por mal manejo de información.
- Formulario demostrativo.
- Referencias consultadas.
- Información del equipo.

---

## Descripción de la App Web

La aplicación **Empresa Segura** representa una página informativa sobre cómo una empresa debe proteger la información de clientes, empleados, proveedores y operaciones internas.

En el sector empresarial se pueden manejar datos como:

- Nombre.
- Teléfono.
- Correo electrónico.
- RFC.
- Datos de facturación.
- Cotizaciones.
- Contratos.
- Pagos.
- Información laboral.
- Información de proveedores.
- Documentos administrativos.
- Información comercial o estratégica.

El propósito de la aplicación es mostrar que esta información debe protegerse mediante medidas legales, administrativas y tecnológicas.
